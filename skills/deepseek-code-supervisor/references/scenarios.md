# 六类项目怎么验

代码改动走二轮六项，运维 / 配置类走第七节的轻量三项 —— 别把配置任务套进代码级回归。
"产物"在不同项目里长得完全不一样，拿到项目先归类，按对应那一节取证。

判断不了就看：入口文件是什么、怎么启动、数据存在哪。

---

## 通用前置：先让它跑起来

不管什么项目，验之前先做这三步。做不了，后面的项目一律标"没验"。

1. **找到启动命令**：`package.json` 的 scripts / `Makefile` / `README` / `pyproject.toml`。
2. **跑起来**：前台跑，看着日志。**别用 `&` 丢后台** —— 父进程一退，服务就没了。
3. **确认它真的起来了**：不是看进程，是看端口和响应。

```bash
netstat -ano | grep :<端口> | grep LISTENING   # 绑在哪个地址
curl --noproxy '*' -i http://127.0.0.1:<端口>/  # 真实响应
```

**别信启动日志的"success"。** 有一次依赖其实没装完，日志照打 `ready`。

## 一、Web 前端（含 H5 / 小程序）

### 产物怎么验

| 层级 | 手段 | 可信度 |
|---|---|---|
| 构建 | `npm run build` 能过，产物目录有文件 | 低（只证明能编译） |
| DOM | jsdom 跑断言 | **中低** —— 不加载外部 CSS，样式问题一律查不出 |
| 真实浏览器 | Playwright / CDP 截图 + 读 DOM 计算样式 | 高 |

### 最容易漏的

1. **加载态 / 空态 / 错误态** —— 三种状态没做，接口一慢就白屏。
2. **超长文本** —— 真实数据一定比 mock 长。
3. **移动端** —— 桌面正常，手机上一半按钮点不到。
4. **样式被旧规则按死** —— 死样式没删，新组件撞名。展开态箭头转了、内容区空白。
5. **dev 正常，build 挂** —— 环境变量、路径大小写、动态导入。

### 必查命令

```bash
npm run build          # 生产构建能不能过
```
构建产物在 `dist/` 里跑一遍，别只测 dev server。

### 必问

- 目标浏览器 / 最低版本？
- 有没有设计稿？还是我按现有风格来？

### 真实翻车

面板展开后一片空白。jsdom 的 DOM 断言全绿 —— 因为样式表根本没加载。
根因是旧版残留的 `.fold-body { display:none }` 没删，新面板又用了 `.fold-*`。

> 样式类改动**必须肉眼看一次**，或者用"选择器命中法"断言：
> `[...styleSheets[0].cssRules].filter(r => el.matches(r.selectorText))` 把命中的规则全列出来。

## 二、后端 API / 服务

### 产物怎么验

```bash
curl --noproxy '*' -i -X POST http://127.0.0.1:8080/api/x \
  -H "Content-Type: application/json" -d '{"a":1}'
```

**必须打真实地址，不能用 mock 代替。** 贴响应体关键字段 + 状态码 + 耗时。

### 最容易漏的

1. **鉴权失败分支** —— 只测了正常登录，没测过过期 token、无权限、跨用户访问。
2. **空请求体 / 多字段 / 超长字段** —— 校验规则一放松就是脏数据。
3. **并发写** —— 两个人同时下单，库存扣成负数。
4. **超时** —— 默认超时太长会拖死连接池；太短会把慢请求误判成失败。
5. **数据库连接没关** —— 压一会儿就 `too many connections`。
6. **错误响应格式不一致** —— 有的返回 `{error}`，有的返回 `{message}`，前端只写了一套。

### 必查

- 所有接口的错误响应结构一致（见 standards 七·1）。
- 列表接口有分页且设了上限。
- 启动时校验了必填配置（缺了要 fail fast，不是跑到一半炸）。

### 必问

- 这接口给谁用？内部调用还是公网？
- 有没有并发量要求？

## 三、数据库与迁移

### 产物怎么验

```bash
# 迁移前
sqlite3 db.sqlite "select count(*) from t"      # 或对应 client
# 跑迁移
# 迁移后
sqlite3 db.sqlite "select count(*) from t; select * from t limit 3"
```

**数行数，看真实数据。** 不看 ORM 报的 affected rows。

### 最容易漏的

1. **空表 / 单行 / 重复键** —— 三个都要跑。代码通常分 `0 / 1 / ≥2` 三支，中间那支最少被测。
2. **回滚** —— 只写了 up，没写 down。出事只能恢复备份。
3. **大表锁** —— 线上加字段、加索引可能锁表几分钟。
4. **字符集 / 时区** —— 存进去是 UTC，读出来变成别的。
5. **软删没过滤** —— 删掉的数据还在列表里。

### 铁规矩

- 迁移前必须有备份，且**验证备份能恢复**。
- 生产不跑没有 where 的 update / delete。先 `select count(*)` 看影响面。
- 破坏性变更分两次发：先加新字段双写，确认无误再删旧字段。

## 四、CLI / 脚本 / 自动化

### 产物怎么验

```bash
./tool --input real.txt > out.txt; echo "exit=$?"
cat out.txt
```

**退出码 + stdout + 产物文件，三样都要看。**

### 最容易漏的

1. **退出码** —— 成功返回 0，失败返回非 0。很多脚本永远返回 0。
2. **管道吃退出码** —— `python x.py | tail` 之后 `$?` 是 tail 的。
3. **无参数 / 错参数** —— 直接崩，报一屏 Python 栈。
4. **路径含空格** —— `C:\Program Files\...` 直接炸。
5. **中断** —— Ctrl+C 之后留下半个文件。
6. **重复执行** —— 跑第二次结果翻倍。

### 铁规矩

- 非 0 退出码要打印"这是什么意思"，别让调用方猜是不是工具坏了。
- 幂等：同样的输入跑两次，结果一样。
- 写入用临时文件 + rename，别原地改。

## 五、第三方集成

支付、登录、短信、对象存储、LLM API 都算。

### 产物怎么验

两层：**mock 一次 + 真实沙箱一次**。只有 mock 不算验过。

### 最容易漏的

1. **超时没设** —— 对方不响应，你的服务一直挂着。
2. **4xx / 5xx 没分开处理** —— 4xx 重试没用（参数错了），5xx 才该重试。
3. **重试不幂等** —— 重试导致重复扣款 / 重复发短信。
4. **额度 / 限流** —— 免费额度用完直接报错，没做降级。
5. **回调没验签** —— 谁都能伪造一个"支付成功"的通知。
6. **密钥泄露** —— 前端直连第三方 API，key 在浏览器里。

### 必问

- 用测试环境还是生产？有没有沙箱账号？
- 失败时业务怎么处理：阻塞、降级、还是排队重试？

### 真实翻车

前端直连 AI API，key 暴露在浏览器里。改法：走后端代理，前端不碰 key。

## 六、部署与发布

### 产物怎么验

```bash
# 1. 构建产物清单
find dist -type f | head -50
find dist -name "*.pem" -o -name "*.key" -o -name ".env*" -o -name "*.sqlite"

# 2. 敏感字面量
grep -rnE "C:[\\/]+Users[\\/]+[A-Za-z]|/Users/[A-Za-z]|<真实姓名>|<学校/公司名>" dist/

# 3. 线上真实请求
curl --noproxy '*' -i https://<域名>/
```

### 最容易漏的

1. **构建把不该发布的东西复制进去了** —— 密钥、数据库导出、工作日志、`.env`。
2. **用状态码判断文件是否暴露** —— 静态托管对不存在的路径常返回 `200 + index.html`（SPA 兜底）。
   要看 `Content-Type` 和内容，不是看 200。
3. **清空旧产物用通配符** —— `rm -rf www/*` 不匹配以 `.` 开头的目录，隐藏文件永远清不掉。
4. **缓存** —— 改了 JS，用户拿到的还是旧版。
5. **环境变量没配** —— 本地有 `.env`，线上没有。
6. **端口只绑了 IPv6 / 只绑了 localhost** —— 本机 curl 通，外面访问不到。

### 铁规矩

- 构建脚本用**白名单**，不用黑名单。以 `.` 开头的条目一律不进产物。
- 构建后加一道闸门：扫到密钥类文件就让构建**失败**，不是打个警告。
- 上线前真的去请求那几个不该存在的路径，确认 404 而不是 200。

### 真实事故

静态构建按黑名单排除（列了 `backend/`、`node_modules/`）。迁移期间新建的 `_deploy/`（含 API 密钥、
JWT 密钥、SSH 私钥、15MB 数据库导出）和 `.workbuddy/` 不在名单里，被原样复制进 `dist/` 上传。
工作日志**真的在公网可下载了**，密钥是被上线前拦下的。

## 七、运维 / 配置类（不起 L2）

域名、DNS、重定向、部署、环境变量、证书、缓存刷新、平台控制台设置，且**没改业务逻辑代码**。

不走六项、不起 L2 子智能体、不跑全量回归。只查三条，逐条写「查了什么 / 看了哪里 / 结论」：

| # | 查什么 | 怎么做 |
|---|---|---|
| 1 | 跳转链 | `curl -I` 逐级跟 301/302，贴每一跳的 Location、最终状态码与内容类型 |
| 2 | 资源终态 | 变动前后的真实对象（DNS 记录 / 平台配置项 / 文件 / 缓存状态），列 before → after |
| 3 | 功能抽样 | 挑 2–3 条真实入口请求，贴状态码 + 响应关键行 |

取证只做 **1 条反例**（如把目标改成一个不存在的地址，确认校验或监控会拦），不放大成批量请求。

硬性上限：单轮 10 分钟、同类外部请求 ≤3 次、HTTP 总请求 ≤8。到了就停，写明未验什么。

外部平台限制（Token 权限 403、配额、限流、部署数上限、需先解绑域名、边缘缓存返回旧内容）→ 记未决项：
不重试、不计入问题数、不升级轮次，写清解除条件。换凭证或换路径最多试一次。

混合任务：代码部分走六项（大改动经弹窗确认才起 L2），配置部分走这三条；L2 只看代码部分。

## 附：类型 → 产物取证 / 泛化验证

| 类型 | 产物取证 | 换一份数据再验 |
|---|---|---|
| 前端 | 真实浏览器截图 / 计算样式 | 换一份更长的数据 |
| 后端 | curl 真实响应 | 换一组更怪的输入 |
| 数据库 | select 出来的行 | 空表 / 历史脏数据 |
| CLI | 退出码 + 输出文件 | 换目录、换路径、跑第二次 |
| 第三方 | 沙箱真实回调 | 断网 / 超时 / 重复回调 |
| 部署 | 线上真实请求 | 清空缓存后再请求一次 |
| 运维 / 配置 | 跳转链 + 资源终态 | 换一条真实入口抽样 |
